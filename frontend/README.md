# BuildLog Frontend

BuildLog의 React 프론트엔드입니다. 개발 환경에서는 `http://localhost:8000/api/v1`의 FastAPI 서버를 호출합니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

## 검사

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
```

환경 변수는 `.env.example`을 참고합니다. 실제 비밀값은 프론트엔드 환경 변수에 넣지 않습니다.
